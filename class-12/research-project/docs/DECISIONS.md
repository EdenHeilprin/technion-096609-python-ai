# Project decisions

| Decision | Current choice | Why it matters |
| --- | --- | --- |
| Study | Sure or gamble, hypothetical points | Keeps the task short and its rules visible |
| Full design | Six ascending offers, version full-v1 | Offer and order cannot be separated in this pilot |
| Confidence | Required integer 1–7, no default | An unanswered question must not become a measurement |
| Example data | Synthetic | Practice output is not evidence about real people |
| Inclusion | Six complete valid rounds | People contribute the same offers to the main summary |
| Main analysis | Descriptive choice rates | Does not treat repeated responses as independent people |
