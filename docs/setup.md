The supported local route is:

- Visual Studio Code;
- a current stable Python 3 interpreter;
- the Microsoft Python extension;
- the downloaded Class 1 folder.

These are separate pieces. VS Code edits and organizes the file. The extension adds Python support. The Python interpreter executes the instructions.

## Verify the setup

1. Download and extract the [Class 1 ZIP](https://github.com/EdenHeilprin/technion-096609-python-ai/raw/main/weeks/01-start/week-01-materials.zip).
2. In VS Code, use **File → Open Folder** and select week-01-materials.
3. Open setup/verify_setup.py.
4. Use **Python: Select Interpreter** and choose the current Python 3 interpreter.
5. Select **Run Python File**.

Expected final line:

    SETUP CHECK PASSED

If setup still fails, use Moodle Technical Help and the browser fallback. Installation trouble should not prevent participation in Class 1.
