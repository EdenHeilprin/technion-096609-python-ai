First teachable module

One file. One run. One deliberate change.

Week 1 establishes the complete programming loop before adding complexity: locate, predict, run, inspect, change, rerun, and explain.

Build

A five-line summary of synthetic reaction-time and accuracy data.

Repair

Create a simple NameError, read the evidence, and fix it.

Verify

Run a dependency-free public check and compare exact output.

Use AI

Ask for a bounded explanation, predict the cause, and test the suggestion.

Final destination

Rebuild a real method—without pretending to rerun the science.

Students reproduce a bounded implementation from a published faculty paper, test it with synthetic or pilot data, and deliver a result another person can run.

Track A

Decision-making experiment

Implement a functioning procedure, condition logic, randomization, validation, and documented data contract.

Track B

OB survey + Python

Build the Qualtrics protocol and a reproducible Python pipeline for cleaning, scoring, checking, summarizing, and visualizing its export.

Evidence of competence

Product + verification + explanation

AI tools are permitted. Students remain responsible for every submitted result. Assessment focuses on working artifacts, deliberate checks, reproducibility, and the ability to explain or modify the work.
