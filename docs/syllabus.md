## Course promise

> **Assistance is normal. Understanding and verification remain yours.**

You will develop enough Python foundations to write, read, run, and debug small programs. You will also learn to work with modern AI chats and coding agents while remaining responsible for the behavior, evidence, privacy, and limitations of the final result.

Consequential coding work is completed on a computer. Programming competence is demonstrated through executable artifacts, deliberate checks, explanation, and modification—not handwritten syntax recall.

## By the end of the course, you can

1. represent behavioral information using appropriate Python values and structures;
2. use conditions, loops, and functions to organize program behavior;
3. make systematic debugging progress using tracebacks, intermediate output, and small tests;
4. read and write simple files and CSV data safely;
5. use a focused set of pandas operations to inspect, transform, summarize, and visualize behavioral data;
6. organize a small project so another person can reproduce its central output;
7. translate a bounded research method into procedure logic, expected data, and checks;
8. use AI for explanation, planning, implementation, debugging, and review while checking consequential claims;
9. explain and make a bounded change to submitted work;
10. recognize privacy, permission, and reproducibility risks in research software.

## Supported working environment

The supported classroom path is:

- VS Code;
- a current stable Python 3 interpreter;
- the Microsoft Python extension;
- GitHub-hosted course files accessed through direct website links;
- pandas and a small documented package set later in the course;
- a free or institutionally funded AI route when an individual tool is required.

PyCharm and Spyder are legitimate alternatives, but classroom troubleshooting and demonstrations use VS Code. Required participation will not depend on purchasing an individual AI subscription.

## Course rhythm

Most classes follow the same loop:

> **Predict or trace → run → explain → modify → test → reflect**

Each released class page provides outcomes, required preparation, runnable code, core practice, an optional stretch, one AI-learning target, exact submission files, and Moodle as the authoritative deadline/submission route.

## AI, privacy, and collaboration

AI chats, autocomplete, and coding agents are permitted. Permission does not transfer responsibility. Students should be able to run, inspect, test, explain, and appropriately protect submitted work.

Use synthetic or explicitly approved public data in ordinary course exercises and public repositories. Never share credentials, identifiers, grades, confidential research material, or private repository content with an unauthorized person or service.
