## Before the first meeting

1. Enter the official Moodle course and keep announcements enabled.
2. Complete the Moodle access survey.
3. Follow the [setup guide](../setup/) for Windows or macOS.
4. Download the [complete Class 1 ZIP](https://github.com/EdenHeilprin/technion-096609-python-ai/raw/main/weeks/01-start/week-01-materials.zip).
5. Extract the ZIP and put the folder somewhere you can find.
6. Bring the computer you expect to use during the course.

Do not spend hours troubleshooting alone. If the setup does not work after approximately 20 focused minutes, use Moodle Technical Help. A browser fallback is available in Class 1.

You do not need to purchase or create a paid AI account for the first meeting.

## Know where things live

| You need to… | Go to… |
|---|---|
| Check an official date or change | Moodle |
| Submit work | Moodle |
| View grades or private feedback | Moodle |
| Ask a course or technical question | Moodle forums |
| Read a class page | This website |
| Download code or synthetic data | A direct link from the class page |

You should not need to browse the GitHub repository structure. The course website provides direct links to the relevant files.

## Two safety rules

1. AI assistance is permitted, but you remain responsible for checking, explaining, and protecting what you submit.
2. Never upload passwords, keys, student/participant identifiers, confidential research material, or private repository content to a public repository or an unapproved AI service.
