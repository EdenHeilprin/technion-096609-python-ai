# Class 1 handout

## Today’s promise

You are not expected to memorize Python syntax today. You are expected to complete one full programming loop:

> find → predict → run → inspect → change → rerun → explain

## Four different things

| Thing | Its job |
|---|---|
| Source file | Stores Python instructions |
| VS Code | Lets you view, organize, and edit the file |
| Python interpreter | Executes the instructions |
| Output or traceback | Provides evidence about what happened |

## First-error routine

1. Read the final traceback line.
2. Name the error type.
3. Locate the referenced source line.
4. Propose one small cause.
5. Change one thing and rerun.

## Evidence questions

- Which exact file ran?
- What did you predict before running?
- Which output changed?
- What stayed unchanged?
- What evidence supports the calculation?
- What input could expose a mistake?

## AI rule for today

Assistance is normal. Verification remains yours.

Ask for an explanation or possible causes. Then inspect the relevant line, predict one repair, run it, and decide whether the observed behavior supports the suggestion.

## Before submission

- Save.
- Close and reopen.
- Run.
- Run the self-check.
- Compare exact output.
