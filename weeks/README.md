# Working course map

The course is planned as 14 two-hour meetings. Approximately 11 introduce new material; three are reserved for integration, practice, rehearsal, demonstrations, and contingency.

| Meeting | Focus | Status |
|---:|---|---|
| 1 | VS Code, GitHub orientation, first Python | New material |
| 2 | Types, variables, strings, input/output | New material |
| 3 | Lists and dictionaries | New material |
| 4 | Conditions, validation, edge cases | New material |
| 5 | Loops, counters, repeated trials | New material |
| 6 | Functions, parameters, return values | New material |
| 7 | Debugging, tracebacks, assertions, tests | New material |
| 8 | Codex workshop: context, scope, diffs, tests, recovery | New material; access pending |
| 9 | Files, CSV, paths, pandas introduction | New material |
| 10 | Pandas transformations, summaries, basic visualization | New material |
| 11 | Experiment/survey architecture and capstone specification | New material |
| 12 | Integration studio | Application; no major new topic |
| 13 | Clinic and rehearsal | Flexible |
| 14 | Demonstrations, studio, catch-up, or contingency | Flexible |

This map remains provisional until the capstone and assessment architecture are tested.
