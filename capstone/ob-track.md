# Track B — OB / Qualtrics plus Python

Working requirements:

- bounded survey/protocol from a published faculty paper;
- Qualtrics implementation;
- synthetic response export;
- Python ingestion and schema checks;
- missing-value handling;
- recoding and scale scoring where relevant;
- exclusions or response-quality checks;
- grouped summaries and at least one useful visualization;
- reproducible cleaned output;
- checks/tests and known limitations;
- setup instructions and README;
- individual explanation or bounded modification.

A Qualtrics form without the Python pipeline is not a sufficient capstone.
