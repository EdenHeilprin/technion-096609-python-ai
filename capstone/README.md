# Capstone

Students reproduce a bounded implementation from a published faculty paper. They replicate the procedure, logic, data contract, and expected outputs—not participant recruitment or the scientific finding.

Two proposed pathways:

- [Decision-making experiment](dm-track.md)
- [OB / Qualtrics plus Python](ob-track.md)

Both pathways must demonstrate comparable Python substance, verification, reproducibility, documentation, and individual ownership.

See the [common capstone rubric and pathway parity map](rubric.md).

The actual faculty papers and platform details have not yet been selected.
