# Browser fallback for Class 1

Use this route only when local Python/VS Code setup cannot be repaired quickly. It requires a modern browser with JavaScript and an internet connection, but no installation or paid AI account.

## Open the official Jupyter browser environment

1. Open [Try JupyterLab](https://jupyter.org/try-jupyter/lab/).
2. Wait for the browser environment to finish loading.
3. Upload week_01_browser_fallback.ipynb from the Week 1 fallback folder.
4. Open the notebook.
5. Run a selected cell with Shift+Enter.
6. Work through the cells in order.

The fallback teaches the same prediction, execution, output, change, and error-repair loop. Its controls differ from VS Code, so local setup should still be repaired after class.

## Important limitations

- The official Jupyter page describes some browser environments as experimental.
- Work is stored in the browser environment; download your changed notebook before closing if you need to preserve it.
- Do not paste real participant data, credentials, or confidential research material.
- If the page fails to load after one refresh, pair with a classmate or use the instructor machine and record the local setup problem for later.

Official reference: [Project Jupyter — Try Jupyter](https://try.jupyter.org/).
