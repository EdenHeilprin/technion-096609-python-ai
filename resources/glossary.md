# Hebrew–English technical bridge

Teaching is in Hebrew; written technical materials are in English. This glossary connects the spoken and written vocabulary.

| English term | Hebrew explanation | Course meaning |
|---|---|---|
| value | ערך | A concrete piece of data, such as `3` or `"choice"` |
| variable | משתנה | A name referring to a value |
| type | טיפוס / סוג נתון | The kind of value and the operations it supports |
| condition | תנאי | An expression used to decide which path runs |
| loop | לולאה | Repetition controlled by data or a condition |
| function | פונקציה | Named reusable behavior with inputs and a result |
| traceback | שרשרת שגיאה | Python's report of where an exception occurred |
| test | בדיקה | A concrete check of expected behavior |
| repository | מאגר קוד | A versioned project stored with its history |
| commit | שמירת גרסה | A named checkpoint in repository history |
| diff | השוואת שינויים | The exact lines added, removed, or changed |

The final glossary should favor clear explanations over literal translation.
