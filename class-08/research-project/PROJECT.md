# Sure or gamble

This project follows a small decision study from a participant's browser to an analysis and research summary.

## Question and design

How does choosing a gamble vary as a guaranteed alternative increases? The full study presents guaranteed offers of **2, 3, 4, 6, 7, and 8 points**, always in that order. The alternative is always a **50% chance of 10 points and a 50% chance of 0 points**. Each round records a choice and confidence from **1 (not at all confident) to 7 (very confident)**.

Points are hypothetical. The task does not draw a lottery outcome or make payments. The same order makes this pilot easy to inspect, but also confounds offer size with round position. The resulting pattern cannot isolate an offer-size effect from an order effect.

The Class 9 minimal version has one offer of 4 points and no confidence question. Its export is not the six-round analysis input.

## Run

Follow `SETUP.md` in the class folder. Run `setup_environment.py`, select `.venv` in VS Code, then run `check_environment.py`. Start a working experiment with `run_experiment.py` and visit **http://localhost:8000**.

The Class 11 analysis uses `analysis/settings.py` to choose the input and identify its source. Never relabel synthetic responses as classroom observations. Keep original exports unchanged.

## What counts as evidence?

- A browser journey showing that the intended responses are required and saved.
- The custom CSV export, checked against one known participant journey.
- An analysis that states how many participants were included and excluded.
- Figures and written claims that can be traced to that analysis.

Changing a field, offer sequence, or confidence scale changes the design. Update the version and analysis rules deliberately; do not silently combine versions.
