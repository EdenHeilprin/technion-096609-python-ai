# Study specification

## Participant journey

The full study begins with instructions, then six choice-and-confidence rounds, followed by a completion page. The offers are 2, 3, 4, 6, 7, and 8 guaranteed points in ascending order. Each is compared with 50% chance of 10 points and 50% chance of 0 points. Every round requires one choice and one confidence response (integer 1–7). Neither response is preselected.

The task measures hypothetical choices. It does not award points or money. There are no time limits, response-time measures, demographic questions, or participant names.

## Record and export

The oTree app is `choice_task`; the session configuration is `sure_or_gamble`. The full design version is `full-v1`; the one-choice teaching checkpoint is `minimal-v1`.

The custom export has one row per participant per round, including uncompleted rows. Columns, in order:

```text
session_code,participant_code,study_version,round_number,sure_points,gamble_high,gamble_probability,choice,confidence
```

`choice` is `sure` or `gamble`; unsubmitted answers are blank, not zero. Session and participant codes are generated by oTree and are not names. Use all three of session code, participant code, and round number to identify a row.

## Analysis decisions

The main description uses participants with six unique valid `full-v1` rounds, a choice and confidence in every round, and the specified offers. Report incomplete participants separately. A malformed value, duplicate key, or incompatible design must be investigated rather than silently repaired or pooled.

For each guaranteed offer, calculate the number and proportion choosing the gamble. Also calculate each participant's proportion of gamble choices. Use participant-level summaries when discussing differences between people. Six responses from one person are not six independent participants.

The main outputs are descriptive. The sample is a classroom pilot, and guaranteed offer is confounded with round position. A confidence comparison by chosen option is also descriptive: participants select those options themselves.
