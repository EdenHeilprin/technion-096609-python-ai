# 096609 — Python, Behavioral Research & AI-Assisted Coding

This repository is the developing technical home of Technion course 096609, formally titled **Quantitative Models in Behavioral Sciences**.

The renewed course is an introduction to Python for graduate behavioral-science students with zero or almost zero coding background. It combines:

- solid Python fundamentals;
- practical work in VS Code and GitHub;
- behavioral-data workflows with pandas;
- construction of a bounded experiment or survey-data pipeline;
- responsible, unrestricted use of modern AI chats and coding agents.

> **Planning status:** This is a public development prototype, not yet the official syllabus.

## Platform roles

- **Moodle:** official announcements, dates, grades, private communication, and authoritative submission records.
- **This repository:** versioned course materials, code, data, instructions, examples, and corrections.
- **GitHub Pages:** the student-friendly course portal and transparent development roadmap.

## Public/private boundary

This public-facing repository must never contain student grades, identity mappings, identifiable research data, hidden tests, or unreleased solutions. Those remain in the private instructor workspace.

## Language

Teaching is conducted in Hebrew. Written materials, code, assignments, and documentation are in English.
