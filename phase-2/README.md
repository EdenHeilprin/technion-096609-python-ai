## The revised Class 8 study

Participants choose a sure **10 points** or a **50% chance of a larger prize**, otherwise zero. Across six decisions, the prize increases. The points are hypothetical. The two supplied Word documents specify the experiment and analysis plan.

## The earlier study in Classes 9–12

Would you prefer a guaranteed number of points or a 50–50 chance of 10 points versus 0? Across six choices, the guaranteed offer increases. These earlier materials also introduce confidence ratings. The choices are hypothetical, with no payment.

Our starting question is: **how does the proportion choosing the gamble vary with the guaranteed offer?** Later, you can examine confidence or propose an improved design.

## Reuse the setup pattern

The [setup guide](SETUP.md) covers Codex, the project environment, and macOS/Windows commands. Setup creates a local `.venv` containing the tested packages in each downloaded project. Setup needs internet access; the experiment, supplied data, and Python analysis then run locally. Codex itself still needs an online connection and available account usage.

Public example data are **synthetic**, not observations from students. A real classroom export can replace the example locally using the Class 11 instructions. Keep real responses out of the public course repository.

## A useful way to delegate

Name the goal, the files that supply context, what must stay unchanged, and how you will check the result. Ask for a plan when the work involves a decision; then authorize the agreed task. Open the files and results, not only the agent's summary.
