# Ungraded baseline and endline diagnostic

## Why we use this

This short diagnostic helps you and the instructor see how your code reading, debugging, verification, and confidence change during the course.

It does **not** affect your grade. Most beginners are not expected to complete the opening form, and an incomplete baseline does not mean you are behind. The task intentionally includes concepts that will be taught later.

## Tool policy

All AI and internet tools are permitted. Use them if you wish. At the end, record only:

- which tool(s), if any, you used;
- what you asked them to help with;
- one suggestion you accepted or rejected;
- how you checked it.

Do not submit full chat transcripts. Never paste credentials, identifiable data, or confidential research material.

## Timing

- Suggested time: 25 minutes.
- Use **Form A** near the beginning of the course.
- Use **Form B** near the end.
- Do not study the form in advance; it is useful only as an honest snapshot.

## Files

- [`form_a.py`](form_a.py) — beginning-of-course form.
- [`form_b.py`](form_b.py) — end-of-course isomorphic form.
- [`response_template.md`](response_template.md) — questions and confidence ratings.

## What to do

1. Open the assigned form in VS Code.
2. Before the first run, record any output prediction you can make. “I do not know yet” is a valid baseline answer.
3. Run the program.
4. Answer the six prompts in the response template.
5. You may edit and rerun the program as often as useful.
6. Save your final code and response using the Moodle activity specified by the instructor.

## What this measures

- reading values and collections;
- tracing changing state through a loop;
- distinguishing runtime output from intended behavior;
- diagnosing and repairing a plausible logic defect;
- anticipating an edge case;
- evaluating an AI suggestion using evidence;
- confidence calibration.

The purpose is growth, not ranking. Results should be used for teaching improvement and student reflection. Any use beyond ordinary course evaluation requires the relevant institutional/ethical review.
