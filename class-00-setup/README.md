# Class 0 — Computer Setup

**Complete this setup before Class 1.** The exact deadline is posted on Moodle.

No previous programming experience is required. You are preparing three separate pieces:

1. **Python 3.13** — the interpreter that runs Python code.
2. **Visual Studio Code (VS Code)** — the application in which we will open and edit code.
3. **The Microsoft Python extension for VS Code** — the connection that helps VS Code work with Python.

All required software is free. You do not need a GitHub account for Class 0.

## What counts as complete?

You are ready when all of the following are true:

- Python 3.13.x is installed.
- VS Code is installed.
- The Microsoft Python extension is installed in VS Code.
- You downloaded and extracted this course repository.
- You opened the repository folder in VS Code.
- You selected a Python 3.13.x interpreter.
- You ran `setup_check.py` and saw `SETUP CHECK PASSED`.
- You completed the Class 0 readiness check on Moodle.

Estimated time: **30–45 minutes**. It may take longer if your computer already has another Python installation.
