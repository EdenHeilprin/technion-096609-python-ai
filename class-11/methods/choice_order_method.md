# Synthetic method excerpt — option order and risky choice

This teaching example is synthetic. It is not a description of a published study.

Participants complete four binary decision trials. Every trial presents a sure option and a risky option. The point values differ across trials.

Each participant is randomly assigned with equal probability to one of two display conditions:

- in the **sure-first** condition, the sure option is displayed as option 1;
- in the **risky-first** condition, the risky option is displayed as option 1.

The participant remains in the same condition for all four trials. The four trials are presented in a new random order for each participant. No option is selected when a trial begins.

The participant responds by pressing `1` or `2`. A trial ends when a response is recorded or when 12 seconds have passed. A timed-out trial continues to the next trial.

For every trial, the stored data must identify the participant, condition, trial, presentation position, first option, selected key, semantic choice (`sure` or `risky`), response time, and whether the trial timed out.

The description does not state what should happen if a participant presses a key other than `1` or `2`.
