## Course description

This course introduces Python programming and the practical use of AI tools in behavioral research. Students learn to read, write, run, and test small programs. A live Codex demonstration connects building and deploying an oTree experiment, collecting responses, analyzing data in R, and drafting a research report. Students then set up these tools on their laptops and use GitHub to prepare and contribute lessons, which they teach in pairs. No previous programming experience is required.

## Learning outcomes

Alongside Python fundamentals, the course develops practical research skills: directing and checking AI-assisted work, collaborating through GitHub, and teaching and presenting ideas clearly.

- Write and explain Python programs using variables, lists, dictionaries, conditions, loops, and functions.
- Locate errors, test expected behavior, and document the purpose of code.
- Read and explain the main steps of AI-generated scripts.
- Give an AI coding agent clear requirements, review its changes, and verify the results.
- Run, adapt, and test an oTree experiment, inspect its data, and follow its deployment to Heroku.
- Use GitHub to propose and revise a contribution through a pull request.
- Explain a topic through a live demonstration and a short activity or discussion.

## Teaching and assessment

Classes combine short explanations, demonstrations, and hands-on practice. The course is assessed on a pass/fail basis; passing requires both of the following:

- **Attendance:** Up to two classes may be missed without justification. Missing a Friday session that covers two classes counts as two absences. More than two absences prevent a passing grade unless justified, for example by reserve military service.
- **Teaching:** Prepare and teach an approximately 30-minute lesson in pairs, with both partners presenting. Assignment details will be provided in Class 10.
